# Transloader for TransImp

This is the OvationPro Transloader for Impression documents.

It was sourced from David Pilling's website: 
https://www.davidpilling.com/wiki/index.php/Impression

It required the inclusion of the OvationPro XL libraries, and I've included the 
two parts that it needs.

CI build works, and we now have what appears to be a working version.
Thanks to David Pilling, obviously, but particularly for explaining where the
!Server came from.
